# 画中有花朵 · 阅读助手

这是《画中有花朵：中国古画中的花卉世界》的网页阅读助手，适合手机端浏览。它不是书籍正文的替代品，而是一个作者伴读式的入口：用问题把读者带进每一章的语境，帮助读者在看画、读书、理解植物与历史之间建立自己的线索。

## 如何使用

直接打开 `index.html` 即可使用。

页面顶部可以横向选择全书导引、13 个章节和全书回想。进入任意章节后，每章分为 5 个小节：

- 氛围与诗境
- 故事入门
- 名画记
- 花卉志
- 读后联想

每个问题后都有一个勾选框，可作为“我是否思考过这个问题”的阅读标记。问题没有标准答案，读者思考过的答案就是最好的答案。

## 文件结构

```text
index.html          页面结构
styles.css          页面样式
app.js              页面交互与渲染逻辑
content.js          阅读内容数据
assets/             封面图、二维码与装饰图
```

## 图片文件

当前页面使用以下图片：

```text
assets/book-cover.jpg       本书封面
assets/buy-qrcode.jpg       购书二维码
assets/author-qrcode.jpg    作者公众号二维码
assets/floral-linework.svg  首页装饰花纹
```

替换图片时，保持文件名不变即可自动更新页面。

## 内容说明

本工具围绕《画中有花朵》的 13 幅古画展开，从东汉到清代，连接古画故事、艺术史、花卉知识、历史语境与读后联想。参考文献集中显示在每章“读后联想”小节末尾。

## 发布说明

这是一个纯静态网页项目，不需要后端服务，也不需要安装依赖。可以直接部署到 GitHub Pages 或其它静态网页托管服务。
